2.1.2: a line is now judged by what it carries, not only by whether it answers — right after connecting, when a transfer stalls, and before the app moves to another line, it pulls a small test file (128 KB) through the line; a line that answers pings but carries nothing is left at once instead of being trusted for another minute; the app tells the service which phone it is by a code (never an identifier of the phone), so a link shared across many phones can be seen; on mobile data it names the network, so the first fetch is filed right; a subscription the service says has ended shows "Expired" at once instead of "Searching for a line…"; the service's word that the line in use is dead on your network is checked with a pull and acted on at the hourly refresh.

2.1.0: no more bursts — after connecting the app measures its lines one or two at a time, a second apart, then one every few seconds while you are using it (nothing while the phone is idle), so a connection never stutters under a wave of probes; a dead line is left within about five seconds, with the replacement proven first; a line only changes for a lead that lasts; what the app learns about each line on your network is remembered for the next time; the subscription answer is now signed by our server and the app accepts no other; the server advises the app which lines work on your network, from what every phone there reported; when a whole network is blocked the app says so instead of searching in silence.

2.0.2: a second measurement of all lines ten seconds after connecting, so the first pick is corrected within seconds when the first, cold measurement read high; the three-minute rounds now vary a little in timing.

2.0.1: the lines are now measured against the service's own target on iPhone too (2.0.0 fell back to the old address), and a refreshed subscription no longer restarts the connection when only Cloudflare's hourly ECH configuration changed; a new user id from the service does reach the running connection.

No server list any more: the app shows the latency of the line it is on, and two buttons, "Test latency" and "Refresh". The lines are measured against the box itself instead of a third party, the results go to the box with the next fetch, a link on the hop's address opens the app at the tap, the link is fetched three ways at once (ECH first, the hop after a head start), and when no line answers the app says so, keeps measuring every minute and fetches fresh lines by itself.

Connecting is immediate: the app no longer tests every server before it connects. It connects on the best server it knows, measures all of them in the background and moves new connections to a clearly faster one by itself, without cutting what is open. A line that stops answering is left within seconds. Test latency never interrupts the connection.
